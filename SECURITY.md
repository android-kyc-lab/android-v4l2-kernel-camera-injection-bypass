# Security Policy

## Supported Versions

We actively support the latest production build distributed via the official
Telegram channel. This GitHub repository serves as the **public documentation
hub** for the V4L2 Injection Framework.

| Version | Supported          |
| ------- | ------------------ |
| Telegram Build v1.0+ | ✅ Fully Supported |
| Source Code (this repo) | ⚠️ Documentation Only |

## Reporting a Vulnerability

We take security and responsible disclosure seriously. If you discover a
vulnerability in the kernel module, the KIMA/FaceGate apps, or the SELinux
bypass stack, please report it **exclusively** via our private Telegram channel:

👉 **[https://t.me/+qDHcyaHWECZiMjY0](https://t.me/+qDHcyaHWECZiMjY0)**

**Disclosure Timeline:**
- Initial report: 24-48 hours for acknowledgment.
- Patch deployment: 5-10 business days depending on the complexity.
- Public disclosure: After the patch is rolled out to all Telegram users.

This repository does not contain the vulnerable binaries; it only documents
the architectural research.
